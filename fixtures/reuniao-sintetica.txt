# Roteiro do corpus de regressão do pipeline de transcrição.
#
# Gere o áudio com:
#   cargo run --release -p isper-cli --bin mkfixture -- fixtures/reuniao-sintetica.txt
#
# O arquivo .wav NÃO é versionado (megabytes de áudio no Git envelhecem mal):
# este roteiro é a fonte, e ele é reproduzível bit a bit na mesma máquina.
#
# Formato de cada fala:
#   <pausa em segundos ANTES da fala>|<falante>|<texto>
#
# O texto é a VERDADE de referência (WER/CER) e o falante é a verdade da
# diarização (DER) — os dois saem prontos ao gerar o áudio.
#
# As vozes vêm do SAPI do Windows (uma só voz em pt-BR nesta máquina) e são
# separadas por perturbação de velocidade: 1,00 · 0,92 · 1,08. É o mesmo
# recurso que o treino de reconhecimento de locutor usa para fabricar falantes
# distintos, e muda o embedding o bastante para o agrupamento ter trabalho.
# LIMITE CONHECIDO: voz sintética limpa não substitui reunião real com áudio
# comprimido pelo Teams. Isto aqui pega regressão; não mede qualidade absoluta.
#
# O roteiro cobre, de propósito: monólogo longo, troca rápida de falante,
# nomes próprios, siglas, termos técnicos, números, silêncio longo,
# interrupção e frases compridas.
