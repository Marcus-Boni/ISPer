# ISPer Portal

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product truth

ISPer is an open-source (MIT) Windows desktop application for local Whisper transcription, global voice dictation and meeting capture. Hold a shortcut in any application, speak, release, and the text lands where the cursor was; record a meeting and get a transcript with the speakers separated. Transcription and speaker diarization run locally. Optional summaries use Groq, Gemini or Claude and send transcript text only when the user configures a provider. Semantic search can use Gemini or an OpenAI-compatible endpoint, including local Ollama.

## Audiences

Dictation and meetings carry equal weight; neither is the secondary feature (confirmed 2026-10-02).

- Professionals who need reliable dictation in any Windows application.
- Teams that record meetings but cannot send confidential audio to a transcription SaaS.
- Technical users evaluating CPU/CUDA requirements, source builds and privacy boundaries.

## Positioning

- Audio never leaves the machine. The only thing that ever crosses is text, and only after the user configures and enables an AI provider.
- Meetings are captured from the computer's own audio: no bot joins the call.
- Open source under MIT, with no subscription. Optional AI providers may bill the user directly.

## Surface modes

- `/`: **Persuade** — make the local mechanism understandable and earn a Windows download.
- `/download`: **Operate** — select CPU or CUDA, installer or portable ZIP, verify integrity and download the correct file.
- `/docs`: **Read** — find an answer and complete a setup or troubleshooting task.

## Primary outcomes

1. A new visitor understands that audio transcription is local and knows that optional cloud AI handles text separately.
2. A Windows user selects the correct download — CPU or CUDA, installer or portable ZIP — without assuming AMD/DirectML support.
3. A user completes installation, first dictation, meeting capture or troubleshooting from versioned documentation.

## Operating Context

- Windows 10 and 11, x64. Two builds: CPU, and CUDA for NVIDIA GPUs. Each ships as an installer and, from 0.20.0 on, as a portable ZIP; the download page shows the ZIPs only when the release carries them.
- GitHub Releases is the canonical binary source. The portal's release data comes from `content/data/releases.snapshot.json`, which a workflow syncs from the published release and which is never edited by hand.
- In a meeting, the desktop app detects Teams calls, records the computer's audio, and keeps meetings in a local Library with search. Recordings can also be imported from audio files.
- The Copilot shows live cards during a meeting. It works on the transcript text with the same AI provider as the summaries, and needs one configured.
- The portal is written in Portuguese (Brazil).

## Capabilities and Constraints

- Summaries: Groq, Gemini or Claude. Ollama is used only for embeddings — semantic search and the Copilot's memory of past meetings — not for summaries.
- No DirectML or AMD GPU acceleration.
- The Android app is experimental and stays out of the portal's positioning: no download is offered, and the documentation guide for recording on the phone (`content/docs/reunioes-e-sistema/celular.md`) is the only place it appears (confirmed 2026-10-02).

## Boundaries

- The portal never records audio, invokes local desktop endpoints or accepts API keys.
- DirectML, local Ollama summaries and the Android app are not advertised as shipped features.
- GitHub Releases is the canonical binary source; Cloudflare Pages serves only the static portal.
- Product claims must remain traceable to the repository, published release or labeled demonstration data.

## Brand Commitments

- The name is written **ISPer.**, with the period in terracotta.
- One mark on every platform: five speech bars centred on a midline and a recording dot, the gesture of the app's own listening indicator. It came from the Android icon, which the user chose over the two other logos the project had (2026-10-02). Every file of it is generated by `scripts/brand.py`; nothing is redrawn by hand.

## Evidence on Hand

- Benchmarks on the landing page, each labelled by provenance: **medido** (a published observation — RTX 4050, Large v3 Turbo q5), **cenário** (an illustrative estimate) or **contrato** (a product guarantee).
- The release snapshot: versions, files, sizes and checksums of the published releases.
- The landing stage is a demonstration with fictitious content, labelled on screen ("Conteúdo fictício · nenhum áudio é capturado").
- There are no testimonials, customer names or logos, press mentions, ratings or user counts. Future work must not invent them.

## Product Principles

1. Local by default: the cloud is opt-in, and it only ever receives text.
2. Every claim is traceable to the repository, a published release or labelled demonstration data.
3. The right download is unambiguous: CPU or CUDA, installer or portable, verified by checksum.
4. Dictation and meetings are one product, presented with equal weight.
