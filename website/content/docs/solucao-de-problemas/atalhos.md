# Atalhos globais

O atalho padrão de ditado é **Ctrl + Alt + Espaço**. Se estiver ocupado, o ISPer tenta Ctrl + Shift + Espaço, Ctrl + Alt + D e Ctrl + Alt + I.

## Gravar outra combinação

Abra **Configurações > Ditado > Gravar atalho** e pressione a combinação desejada. A alteração vale imediatamente, sem reiniciar.

## Atalhos da reunião

| Ação | Padrão |
|---|---|
| Iniciar ou parar reunião | Ctrl + Alt + M |
| Marcar momento | Ctrl + Alt + K |

## Quando não funciona

- Evite combinações reservadas pelo Windows ou pelo aplicativo em foco.
- Alguns programas elevados podem impedir a colagem por um aplicativo sem elevação.
- Confira no menu da bandeja qual combinação foi registrada de fato.
- Use o botão na tela Início para separar problema de captura de problema de atalho.
